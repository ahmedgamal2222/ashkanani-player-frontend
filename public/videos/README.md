Cloudflare Pages يرفض الملفات الأكبر عند النشر):

| الملف | الوصف |
| --- | --- |
| `ahmedhussin1.mp4` | الفيديو التعريفي للاعب ومهاراته (مُستخدم حاليًا في معرض الوسائط) |
| `hero-film.mp4` | **غير مُستخدم حاليًا** — كان خلفية الهيرو، والهيرو الآن **صورة ثابتة** (`player.heroImageUrl`) لإسراع فتح الصفحة وتخفيفها على الجوال. الملف باقٍ في المجلد للمرجعية فقط ولا يُستدعى من أي مكوّن (حُذف `HERO_FILM` من `lib/videos.ts`) |

> ملف `hero-film.mp4` نسخة باسم ASCII آمن للروابط
> (المصدر: `WhatsApp Video 2026-09-28 at 7.41.23 AM.mp4`) — الاسم الأصلي باقٍ في المجلد
> للمرجعية، وللاستخدام على الويب يفضل الاسم اللاتيني بلا مسافات حتى يعمل الرابط على كل
> المتصفحات والاستضافات.

> **فيلم «أبرز اللقطات»** كان ملف MP4 محليًا بحجم 188MiB (ولهذا فشل النشر على Cloudflare
> Pages)، فاستُبدل برابط يوتيوب: `https://www.youtube.com/watch?v=8XS6uN7JzHY` —
> يُضمَّن داخل قسم `#showreel` عبر `getYouTubeEmbedUrl` في `lib/video.ts` ولا يُحمَّل
> إطاره إلا بعد ضغط الزائر (`lib/videos.ts → SHOWREEL`).

> الفيديو الآخر (المنتخب — بطولة غرب آسيا للشباب) يُضمَّن عبر رابط يوتيوب داخل معرض الوسائط،
> وروابط يوتيوب تُحوَّل تلقائيًا إلى تضمين داخلي عبر `lib/video.ts`.

## خطوات الإضافة

1. انسخ ملفات الفيديو (MP4 / H.264) إلى هذا المجلد مع مراعاة حدّ الـ 25MiB للملف الواحد.
2. لتغيير الأسماء أو إضافة فيديوهات جديدة، عدّل جدول `media` في `../backend/seed.sql`
   (الحقل `url` = `/videos/اسم-الملف.mp4`) ثم أعد تنفيذ:

   ```bash
   cd ../backend
   npm run db:seed          # محليًا
   npm run db:seed:remote   # على Cloudflare
   ```

> ملاحظة الأداء: للملفات الكبيرة استخدم **يوتيوب** (كما في فيلم أبرز اللقطات) أو
> **Cloudflare R2** مع الرابط المباشر، بدلًا من تخزينها في المستودع.
