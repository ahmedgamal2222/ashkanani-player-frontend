# مجلد الفيديوهات — Videos

ضع هنا ملفات الفيديو الرسمية للاعب:

| الملف | الوصف |
| --- | --- |
| `ahmedhussin1.mp4` | الفيديو التعريفي للاعب ومهاراته (مُستخدم حاليًا في معرض الوسائط) |

> الفيديو الآخر (المنتخب — بطولة غرب آسيا للشباب) يُضمَّن عبر رابط يوتيوب داخل معرض الوسائط،
> وروابط يوتيوب تُحوَّل تلقائيًا إلى تضمين داخلي عبر `lib/video.ts`.

## خطوات الإضافة

1. انسخ ملفات الفيديو (MP4 / H.264) إلى هذا المجلد.
2. لتغيير الأسماء أو إضافة فيديوهات جديدة، عدّل جدول `media` في `../backend/seed.sql`
   (الحقل `url` = `/videos/اسم-الملف.mp4`) ثم أعد تنفيذ:

   ```bash
   cd ../backend
   npm run db:seed          # محليًا
   npm run db:seed:remote   # على Cloudflare
   ```

> ملاحظة الأداء: ضع الملفات الكبيرة على **Cloudflare R2** واستخدم الرابط المباشر
> (مثال: `https://cdn.example.com/videos/highlights-2025.mp4`) بدلًا من تخزينها في المستودع.
